### Como trabalho nos projetos

Os números que aparecem nos READMEs saem de comandos ou consultas que estão no próprio repositório, então dá para rodar de novo e conferir. Todos os projetos têm testes (pytest ou `node:test`) rodando no GitHub Actions. O `docs/COMO-FUNCIONA.md` de cada um explica o projeto em linguagem simples, e nos três projetos de dados o `docs/DECISOES.md` guarda as escolhas que fiz e o motivo de cada uma. Antes de usar uma fonte externa, leio os termos de uso e o `robots.txt` e limito o ritmo das requisições.
